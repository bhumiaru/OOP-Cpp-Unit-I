## About the Repository

This repository contains the C++ programs completed as part of **Unit I** of the **Object Oriented Programming using C++ (OOPS)** course.

The programs demonstrate fundamental C++ programming concepts including data types, decision-making, loops, arrays, functions, classes and objects, constructors and destructors, static members, inline functions, and friend functions.
