## 📋 Programs Included

### Program 01 — Basic Single Inheritance
Demonstrates the basic concept of single inheritance where one derived class inherits properties and functions from a single base class.

### Program 02 — Protected Member Access
Demonstrates the use of protected members and how they can be accessed by a derived class.

### Program 03 — Public versus Private Inheritance
Demonstrates the difference between public and private inheritance and their effect on accessibility of inherited members.

### Program 04 — Multilevel Inheritance
Demonstrates inheritance through multiple levels, where a derived class becomes the base class for another class.

### Program 05 — Hierarchical Inheritance
Demonstrates hierarchical inheritance where multiple derived classes inherit from a single base class.

### Program 06 — Multiple Inheritance
Demonstrates multiple inheritance where a single derived class inherits from more than one base class.

### Program 07 — Multiple-Inheritance Ambiguity
Demonstrates ambiguity that can occur when multiple base classes contain members with the same name and shows how scope resolution can be used.

### Program 08 — Constructor and Destructor Order
Demonstrates the order in which constructors and destructors are called in an inheritance hierarchy.

### Program 09 — Parameterized Base Constructor
Demonstrates how a derived class can initialize a parameterized constructor of its base class.

### Program 10 — Function Overriding
Demonstrates function overriding where a derived class provides its own implementation of a function inherited from the base class.

### Program 11 — Abstract Class
Demonstrates the use of an abstract class and pure virtual functions in C++.

### Program 12 — Virtual Base Class and Diamond Inheritance
Demonstrates virtual inheritance and its use in resolving the diamond inheritance problem.

### Program 13 — Friend Class
Demonstrates the concept of a friend class and its ability to access private and protected members of another class.

### Program 14 — Nested Class
Demonstrates the concept of defining a class inside another class.

### Program 15 — Vehicle Rental System
A mini-project demonstrating inheritance through a vehicle rental system using different vehicle types.

### Program 16 — Employee Payroll System
A mini-project demonstrating Object-Oriented Programming concepts through an employee payroll system.
